# Conceptual Class Diagram (CCD)

แผนภาพระดับ **แนวคิดโดเมน** (ไม่ใช่ไดอะแกรม implementation ทุกคอลัมน์) สอดคล้องกับโมเดลใน `backend/app/models/`

| ไฟล์ | เนื้อหา |
|------|---------|
| `01_conceptual_core.puml` | แกนหลัก — แบ่งแพ็กเกจ (ผู้ใช้ / โซน / ผล+แจ้งเตือน) จัดเลย์เอาต์ซ้าย→ขวา |
| `02_conceptual_extended.puml` | Camera, ViolationLog, SafetyRule, DailyStats และเชื่อมกับ Zone / Detection / User |

## การอ่านคู่กัน

- ใช้ **01** เป็นแผนภาพหลักในเล่ม (กระบวนการตรวจจับ → แจ้งเตือน)
- ใช้ **02** เมื่อต้องการแสดง **กล้อง / บันทึกการฝ่าฝืน / กฎ / สถิติรายวัน**

## ส่งออกเป็นรูป

เหมือน SSD: เปิดไฟล์ใน PlantUML แล้ว Export PNG/PDF  
ถ้าตัวอักษรเล็ก ให้เพิ่มหลัง `@startuml` เช่น `scale 1.1`

## หมายเหตุหลักการ (เขียนในเนื้อหาเล่มได้ ไม่บังคับบนแผนภาพ)

- **Detection** หนึ่งรายการต่อหนึ่งรอบการรัน (รูปหรือวิดีโอ)
- **Alert** หลายรายการต่อหนึ่ง Detection ได้ (ตามรายการการฝ่าฝืน)
- **ViolationLog** เป็นมุมบันทึก/ตรวจสอบย้อนหลัง อาจผูกกับกล้องและ Detection
- **SafetyRule** กับ **Zone.requiredPpe** อาจสอดคล้องกันทางความหมายของประเภท PPE แม้ไม่ลากเส้น FK ในแผนภาพ
